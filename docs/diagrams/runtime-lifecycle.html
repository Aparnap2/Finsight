FinSight — Cognitive Runtime Lifecycle

Request → Pipeline → Final Report

Query: "Analyse revenue variance for Q1 2026 — identify key drivers and flag material variances"

Pipeline (5 Nodes)

  • 1. Planner — Decomposes query into ActionPlan (LLM, 1 call)
  • 2. Retriever — Gathers raw data from sources (deterministic)
  • 3. Executor — Routes to 6 engines (deterministic, Decimal math)
  • 4. Verifier — Rule-based checks (confidence, evidence, contradictions)
  • 5. Reflection — Decides finalize or revise (deterministic)

Loop Decision

  • finalize → Generate report, capture telemetry, halt
  • revise → Re-route to Planner (max 5 iterations)
  • Triggered by: confidence < 0.7, gaps found, validation failures
  • Each iteration refines ActionPlan based on previous results

LLM Boundary

  • Exactly 2 LLM calls per standard pipeline run
  • Planner: natural language → ActionPlan decomposition
  • Report Commentary: assertions → narrative generation
  • Zero LLM calls in Executor, Verifier, Reflection, or any engine
