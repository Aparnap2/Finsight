System Architecture

Architecture

  • 5 ADRs documenting every major design decision
  • 4-layer dependency flow: apps → agents → finance → shared
  • Iterative loop max 5 iterations, Reflection decides finalize/revise
  • LLM boundary: 2 calls per pipeline, zero math

Domain

  • 6 deterministic engines: formula, variance, scenario, driver, forecast, KPI
  • Validation suite: data quality, materiality, evidence, policy enforcement
  • Assertion model: 5 types × 4 support levels, deterministic confidence
  • Monetary: 100% Decimal arithmetic, zero float

Quality

  • 342 tests passing, ruff clean, mypy strict
  • 22 golden datasets × 12 metrics = 264 data points per regression
  • Regression harness: YAML thresholds, breaking change detection
  • Audit trail: every claim traces to source via evidence IDs
